This is **not** a greenfield build — a substantial Plan Engine already exists
(`backend/src/modules/plan-engine/`, 12 backend files + 5 spec files + 12 frontend
components), built earlier this session against an earlier, thinner understanding of
the module. This audit (performed via a dedicated read-only Explore pass over the
actual source, schema, and tests — not assumed) found the existing implementation is
functionally real (versioned, persisted, tested, live-wired to Cohort/Pathway Engine)
but diverges from this v3.0 spec in several concrete, load-bearing ways, listed below.

Status legend: **PASS** (matches v3.0, verified against source) · **PARTIAL** (exists,
materially incomplete or diverges from the spec) · **GAP** (spec requirement, no
current implementation) · **NOT IMPLEMENTED** (named scope boundary — spec marks it
PROPOSED/requires-sign-off, or no supporting infrastructure exists anywhere in this
codebase for any module, consistent with prior Cohort/Pathway Engine scope decisions).
